### Production recovery (TODO)

Для production нужно будет разработать отдельный скрипт `recover-certs.sh`:

1. Сгенерировать новый Root CA (в HSM)
2. Переподписать Intermediate CA новым Root CA
3. Перевыпустить все сертификаты сервисов (gateway, user-service, kafka, keycloak, ...)
4. Обновить truststore во всех сервисах
5. Перезапустить все контейнеры с новыми сертификатами

**Когда реализовать:** при переходе на Kubernetes / geo-reserved setup.

# Карты в ASOP: источник тайлов, юридические аспекты, офлайн-режим

> Документ описывает, какие карты используются в platform (web-admin + пассажирское
> приложение), кто их разрабатывает, лицензию/стоимость, а также способы сделать
> подложку доступной без интернета (офлайн).

## 1. Какие карты используются

Обе карты используют **стандартные растровые тайлы OpenStreetMap** (слой **MAPNIK**),
но через разные библиотеки рендеринга:

| Клиент | Библиотека | Источник тайлов | Код |
|--------|------------|-----------------|-----|
| **web-admin** (`LiveMapPage.tsx` + `RouteEditorPage.tsx`) | Leaflet (`react-leaflet`) | `https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png` | `frontend/web-admin/src/pages/LiveMapPage.tsx`, `frontend/web-admin/src/pages/routes/RouteEditorPage.tsx` |
| **пассажирское приложение** (Samsung) | osmdroid (`TileSourceFactory.MAPNIK`) | тот же публичный тайловый сервер OSM | `frontend/passenger-app/app/src/main/java/ru/asop/passenger/ui/MapScreen.kt` |

По сути это **одинаковая базовая подложка OSM**, только отрисованная через разные
движки (Leaflet в вебе, osmdroid на Android).

## 2. Кто разрабатывает и поддерживает карты

- Карты OSM — это не «собственность» какой-то компании, а **открытая картографическая
  база**.
- Разрабатывает и поддерживает **OpenStreetMap Foundation** совместно со всемирным
  сообществом волонтёров-мапперов (править может любой через редакторы iD / JOSM).
- **Лицензия данных — ODbL** (Open Database License): можно свободно использовать,
  копировать, распространять, но с указанием авторства и под той же лицензией.
- **Рендер подложки** (сам слой MAPNIK) — базовая визуализация данных OSM.

### О Крыме

- OSM отображает **фактическое физическое состояние** территории с подписями на
  местных языках.
- Юридическая атрибуция Крыма (чьей административной территории он принадлежит) —
  вопрос политический, **OSM этого вопроса не решает**: карты просто показывают
  геометрию и названия объектов. При необходимости отображение государственных
  границ настраивается отдельно в стиле карты.

## 3. Бесплатность и ограничения

- Тайлы с `tile.openstreetmap.org` — **бесплатны**, но **только для допустимого
  (fair use) объёма**: мелкий некоммерческий или небольшой трафик (≈ 1–2 тайла/сек
  на один клиент).
- Для **масштабного коммерческого продакшена с тысячами терминалов** прямая тяга
  тайлов с публичных OSM-серверов **запрещена политикой допустимого использования**:
  можно получить блокировку IP. Решение — **self-hosted тайл-сервер** (см. ниже)
  или платный провайдер тайлов.

## 4. Работа без интернета. Можно ли скачать локально?

**Сейчас — карты полностью сетевые, без интернета подложки нет.**

- **web-admin:** Leaflet (и LiveMap, и RouteEditor) тянет тайлы напрямую с `tile.openstreetmap.org`. Без сети
  подложка пустая; маркеры и линии (данные) рисуются, но фона нет. Кэшируется только
  то, что успел закешировать браузер.
- **пассажирское приложение:** osmdroid по умолчанию **кеширует показанные тайлы на
  диск** (приватная БД тайлов + `osmdroid` SharedPreferences), но это **кэш последней
  сессии, а не полноценный офлайн-режим**. После очистки кэша без сети подложка исчезает.

### Как сделать офлайн (варианты)

1. **osmdroid offline — рекомендация для Android:**
   - Скачать архив тайлов (например, через приложение **OsmAnd**, или генератором
     **MOBAC** / `mapcreator`).
   - Положить `.zip` в каталог osmdroid приложения и подключить `OfflineTileProvider`
     (или использовать штатный `IFilesystemCache` / предзагрузку).
   - Тайлы OSM легально экспортируются для этих целей — лицензия ODbL позволяет.

2. **web-admin — локальный тайл-сервер или векторные тайлы:**
   - Собирать растровые тайлы локально через nginx-кэш / tile-proxy.
   - Либо перейти на **векторные self-hosted тайлы** (MBTiles + `tileserver-gl` /
     `openmaptiles`).

3. **Общий self-hosted тайл-сервер в Docker для обоих фронтов** (рекомендуемый
   целевой вариант):
   - Поднять внутри инфраструктуры (`tileserver-gl` / `openmaptiles`) один источник.
   - web-admin и пассажирское приложение подключаются к нему.
   - Плюсы: полный офлайн, нет лимитов/блокировок OSM, единая точка обновления.

## 5. Рекомендация

Для продакшена с сотнями/тысячами терминалов:
- использовать **self-hosted тайл-сервер** (векторные или растровые OSM-тайлы),
- для Samsung-приложения включить **офлайн-кэш osmdroid** (ZIP-тайлы или предзагрузку),
- не тянуть тайлы напрямую с публичных OSM-серверов на большой трафик.
